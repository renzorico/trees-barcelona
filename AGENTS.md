# Barcelona Plantings

Static single-page 3D map of Barcelona street trees by planting date. No build step.

- Stack: plain HTML/JS, MapLibre GL 4.7.1 and deck.gl 9.0.38 from jsDelivr. Data prep in Python (`prep.py`, pandas).
- Run: `python3 -m http.server 8765`, open `index.html`. `?film` hides controls for screen recording.
- Data: `data/arbrat_viari.csv` is gitignored; `trees.json` (generated by `prep.py`) is committed.
- Keep the 22% dated caveat and the Open Data BCN CC BY 4.0 credit visible on the page.
- New dependencies must be flagged to the user.
- Audit report: `audits/UX-2026-11-05-deep.md` (open items D-004, D-008 to D-017).
