# UX audit: trees (Barcelona Plantings)  2026-11-05  mode: deep
Commit: n/a (not a git repo)  Auditor model: claude-sonnet-5-5  Evidence: screenshots at 375, 768, 1440 (dark + light load/playing; 1440 focus; 375 + 1440 dark barri-panel; 1440 film a/b) + full source read (index.html, prep.py) + read-only CSV check

## Verdict
Usable on the main path: autoplay, pause, speed, scrub and barri filter all work, and there are no a11y blockers on the primary flow. It is distinctive (condensed numerals, mono UI, real data, purposeful motion), but it drifts from the Renzo signature on palette and type roles. The biggest issues are the missing failure and orientation states: no fallback when WebGL or the CDN fails, no map context, and a panel with no focus management. Share metadata is missing, and the map is clipped at 768 wide.

## Scores
- Generic-AI score: 1 (distinctive), tells counted: A8-L (only the fetch error is designed; no WebGL/CDN failure state, bare "Loading" text)
- Signature: partial; concept in one sentence: a night-map title sequence, where a giant condensed tabular counter and a lime plot-by-plot drop-in animation carry a real open dataset.
- Signature match (Renzo spec): does not match. Layout is left-aligned and asymmetric, and there are no hard-ban hits. Palette (lime on near-black, cool grey light theme, green accent) and type roles (mono as body, condensed grotesque for numbers) deviate. There is no notebook structure (no method, margin notes or source links).
- Defects: critical 0, high 0, medium 8, low 9

## Top 5 to fix first
1. D-001 Add WebGL/CDN failure states and a real loading state.
2. D-006 Fix the map framing: it clips at the right edge at 768 and auto-rotate makes it worse.
3. D-002 and D-003 Fix panel focus management (focus in, Escape, focus return) and give the canvas a visible focus ring.
4. D-007 Add meta description, OG/Twitter image, favicon and theme-color.
5. D-005 Add map orientation (a neighbourhood outline or name when a barri is selected, and a hint that tree dots are clickable).

## Defects (Part C)

### [MEDIUM] D-001 No failure state for WebGL or CDN scripts; misleading message
- Where: index.html:142-143, 518-526, 529-532
- Status: verified (code); the outcomes are inferred from MapLibre/deck behaviour
- Standard: Nielsen 9 (help users recover from errors), 1 (system status)
- Problem: `.catch` shows "Could not load the tree data" for any exception. If maplibre or deck fail to load from jsDelivr, `start()` throws and the user is told the data failed. If WebGL is unavailable the map never fires `load`, there is no `map.on('error')`, and the page stays on "Loading" forever. There is no `<noscript>`. The loading state is bare grey text for a 3.5 MB JSON plus two large CDN bundles.
- Fix: Separate messages ("Could not load the map library", "This needs WebGL"). Add `map.on('error')`. Add a loading line with progress or size, and a `<noscript>`.

### [MEDIUM] D-002 Barri panel has no focus management
- Where: index.html:357-363, 439-443 | 1440-dark-barri-panel.png, 375-dark-barri-panel.png
- Status: verified (code)
- Standard: WCAG 2.4.3, 2.1.2 / ARIA dialog-disclosure pattern
- Problem: Opening the panel does not move focus into it. There is no Escape handler. Closing or selecting hides the panel and focus drops to the body. At 375 the 320 px panel covers all controls while playback continues behind it. 73 buttons with no search.
- Fix: Focus the first item or the close button on open, close on Escape, return focus to `#barriBtn`. Pause playback while the panel is open on phones, and add `scroll-margin` plus a type-ahead or filter input.

### [MEDIUM] D-003 Map canvas focus ring removed
- Where: index.html:43 (`.maplibregl-canvas { outline: none; }`)
- Status: verified (CSS); canvas focusability is the MapLibre default (suspected)
- Standard: WCAG 2.4.7
- Problem: The interactive map canvas takes keyboard focus (MapLibre sets tabindex=0) and the ring is removed with no replacement. 1440-dark-focus.png shows no visible focus indicator anywhere, so I could not confirm the global `:focus-visible` rule (index.html:39) in a captured state.
- Fix: Replace `outline:none` with `.maplibregl-canvas:focus-visible { outline: 2px solid var(--accent); outline-offset: -2px; }`, or set `tabindex="-1"` on the canvas if keyboard map pan is not wanted.

### [MEDIUM] D-004 Data not available to non-visual users
- Where: index.html:99, 132 (`aria-live="off"`), 133-136
- Status: verified
- Standard: WCAG 1.1.1, 4.1.3
- Problem: The map is `role="img"` with a one-line label. The count, the actual content of the page, is explicitly not announced. Only the year is exposed through the slider. There is no text alternative such as peak year or totals per year.
- Fix: Add a visually hidden summary (for example "32,130 dated trees; most planted in 2025: 2,951"). Add a polite live region that updates on pause, on scrub release and on end, not per frame.

### [MEDIUM] D-005 No orientation, selection feedback or affordance on the map
- Where: index.html:511-516 (style has only a background layer), 487-492 | 1440-dark-load.png, 768-dark-load.png
- Status: verified
- Standard: Nielsen 6 (recognition over recall), 1; WCAG 1.3.1
- Problem: There are no streets, coast, labels or north arrow, and the bearing rotates by about 45 degrees over playback. A viewer unfamiliar with Barcelona cannot place anything. A selected barri has no outline or label on the map, only text in the caption. Clicking a tree to select its barri is undiscoverable (no hint, no pointer cursor).
- Fix: Draw the selected barri's convex hull or bounds as a hairline, label it in the mono face, add one line of hint copy, and set `cursor: pointer` on hover over a pickable layer.

### [MEDIUM] D-006 Map clipped at 768 and small at other sizes
- Where: 768-dark-load.png, 768-light-load.png @ 768, right edge (map touches x=768); index.html:366-376, 160-161
- Status: verified
- Standard: WCAG 1.4.10 / C2 (no clipped content)
- Problem: `cameraForBounds` ignores pitch and bearing (the code comment says so), so `SIDE_PADDING_PX = 40` is not honoured. At 768 wide the Besos/Forum edge is cut. Auto-rotate (index.html:474) adds about 45 degrees over 32 s, so more is clipped as it plays. At 1440 and 375 the city fills only about 40% and about 70% of the width, which leaves large dead area.
- Fix: Compute the fit from the rotated, pitched bounds (fit after `setBearing`/`setPitch`, or add padding proportional to the tilt). Cap auto-rotate at roughly +-15 degrees.

### [MEDIUM] D-007 No share metadata, favicon or theme-color
- Where: index.html:3-10 (only title, viewport)
- Status: verified
- Standard: C6 (metadata, link previews)
- Problem: No meta description, canonical, og:title/og:image, twitter:card, favicon or theme-color. This is a map meant to be shared and screen-recorded; link previews will be blank.
- Fix: Add description, OG/Twitter tags with a still from the film mode (frame ~2020), an SVG favicon and `<meta name="theme-color">` for both schemes.

### [MEDIUM] D-008 Likely load and runtime cost
- Where: index.html:9, 142-143, 280, 285-317, 529; trees.json 3.5 MB; prep.py:57 (field `g`)
- Status: suspected (no tooling run; software WebGL)
- Standard: CWV (LCP, INP)
- Problem: (a) The full `deck.gl@9.0.38/dist.min.js` suite is loaded for ScatterplotLayer only. (b) Archivo is requested with all axes (wdth 62..125, wght 100..900) though only 62% width at 800 is used (index.html:50,74). (c) The `g` (species group) array is exported for 145k rows and never read. (d) `new deck.DataFilterExtension` is created in `makeLayers()` every frame (line 280), and new `subarray` data objects are created every frame, which likely forces extension and attribute re-init per frame. (e) The JSON has no gzip evidence.
- Fix: Use `@deck.gl/core`, `layers`, `extensions` and `mapbox` modules. Limit the font URL to `Archivo:wdth,wght@62,800` plus the needed range. Drop `g` from prep.py. Hoist the extension to a constant and cache the `data` objects; only change `length` and filter range. Serve the JSON compressed.

### [LOW] D-009 Faint base points under 3:1
- Where: index.html:19, 31, 286 | 1440-dark-load.png, 1440-light-load.png
- Status: verified (calculated)
- Standard: WCAG 1.4.11
- Problem: Undated trees (#3a3e46 on #07080a = 1.87:1; #aab0b8 on #e9ecee = 1.84:1) draw the whole street geography, but the contrast is under 3:1. Timeline track and ticks (hair) are 1.45:1 dark and 1.58:1 light. The thumb is accent (16.96:1), so the slider state is perceivable.
- Fix: Lift undated to about 3:1 (for example #5b606a dark, #8a9099 light) or accept it as decorative and say so. Raise `--hair` for the track to 3:1.

### [LOW] D-010 New vs old planting hue is weak in light mode
- Where: index.html:29-30 (#3d6e00 vs #2b2f36 = 2.19:1); dark: #c6ff3d vs #cfd3d8 = 1.27:1
- Status: verified (calculated)
- Standard: WCAG 1.4.1 (colour not sole cue)
- Problem: The "hot" fade from accent to old reads mostly by hue. Radius (15 m to 6 m) and the ring give a second cue, so this is a mitigated low.
- Fix: Keep the size cue, and in light mode pick an accent with more luminance distance from `--old`.

### [LOW] D-011 Play/Replay label goes stale; dead branch
- Where: index.html:387-390, 378-381, 416-421
- Status: verified
- Standard: Nielsen 1, 4
- Problem: `if (!playing) setPlaying(false)` does nothing. After the run ends, pressing Home or scrubbing back leaves the button saying "Replay" mid-timeline and at 2007.
- Fix: Call `setPlaying(playing)` after any time change, or derive the label in `updateHud()`.

### [LOW] D-012 Controls jump when barri is selected; caps inconsistent
- Where: index.html:53-61, 107-108, 354 | 1440-dark-load.png @ top-right
- Status: verified
- Standard: C5 consistency
- Problem: `#clearBarri` appears as a new 44 px row and pushes the play/speed row down. `.caps` is set on `.top-right` and the panel, but `button` elements do not inherit `text-transform` (UA reset), so "Barri: All Barcelona", "Pause", "Close" render mixed-case beside uppercase "BARRIS" and captions. A long name (for example "Diagonal Mar i El Front Marítim del Poblenou") in the button at 375 may collide with the h1 (suspected, not captured).
- Fix: Reserve the Clear row space or place it inline. Add `button { text-transform: inherit; }` or drop `.caps` on buttons. Truncate the barri label with ellipsis.

### [LOW] D-013 Barri list order and content
- Where: index.html:425-438; 1440-dark-barri-panel.png

### [LOW] D-015 Pre-2007 dates silently labelled "no date on record"

## Missing signature (Part B and Renzo spec)

### S-001 Palette (Part B3 / Renzo signature)
- Observation: Dark is #07080a with lime #c6ff3d. Light is cool grey #e9ecee with green #3d6e00 (index.html:13-31). The spec calls for warm paper around #f5f1e8, warm ink and signal orange around #e4572e. Accent is also used for new dots, active speed, timeline fill and hover, so it carries four jobs.
- Direction: (a) retint light to warm paper plus orange accent and keep lime only for "new this instant"; (b) keep dark, but swap lime for the orange accent and warm the ground; (c) reduce accent jobs to "new plantings" plus the focus ring.

### S-002 Typography roles (Part B2 / Renzo signature)
- Observation: Mono is body and chrome (index.html:36), Archivo condensed 800 carries year and count (index.html:50,74). The spec has mono for headings, labels and numbers, and a clean sans for body. There is no sans body and no real prose to carry hierarchy.
- Direction: (a) set the big numerals in JetBrains Mono and keep Archivo only as body; (b) keep Archivo numerals as a deliberate exception and add a sans for the caption and credit; (c) drop the Archivo wdth axis if switching.

### S-003 Concept: technical notebook (Part B1/B6/B8)
- Observation: There is no method note, margin annotation or data caveat in the layout beyond a one-line credit. There is no link to the code or the CSV. The copy has one dry line ("Faint points have no date on record") and nothing else says who made it or why.
- Direction: (a) add a margin note column at 1440 with 3 to 4 facts (peak year 2025: 2,951; 22% dated); (b) add a "how this was made" footer line linking the repo and the dataset; (c) annotate peak years on the timeline.

### S-004 Native annotated chart (Part B5)
- Observation: The timeline is custom, but it shows only the year, not the rate. Bursts (2010: 2,037; 2025: 2,951) are invisible until they happen.
- Direction: add a per-year sparkline behind the track, or tick heights scaled to the year count.

### S-005 Details and craft (Part B9)
- Observation: No favicon, OG image, designed loading/error states or print styles (see D-001, D-007). Selection colour (index.html:38) and focus style (index.html:39) exist.
- Direction: add an SVG favicon (a single lime dot), an OG still from film mode, and a designed failure card.
